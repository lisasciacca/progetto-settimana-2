# progetto-settimana-2

Introduzione

Il progetto di questa settimana verteva sulla creazione di una pagina web clone dell'omonimo sito Amazon.
Per la struttura del sito abbiamo usato il linguaggio html al quale abbiamo collegato un foglio CSS per
lo stile e un foglio di javaScript per le funzioni.

HTML
Ho lasciato invariata la struttura dell'html e ho seguito la consegna nei commenti.

CSS
Anche in questo caso ho lasciato invariata la parte già presente nel file e ho lavorato sul resto usando
la tecnica del box model. Andando a tentativi, ho trovato le dimensioni giuste per replicare l'esempio 
fornito dal professore. Ho usato i colori forniti e per quelli mancanti ho usato l'estensione colorZilla.

javaScript

Per ogni esercizio ho inserito un console.log che attinge dall'array e uno con inserimento manuale per
fare i test.
Come richiesto dalla traccia in piattaforma, e dai commenti del codice stesso, ho creato una griglia di
prodotti a partire dall'array di partenza direttamente da javaScript intervenendo in modo minimo nel 
codice html. Ho dovuto cercare online e nel mio libro di testo come applicare le istruzioni fornite dalle
slide in piattaforma.
Ho preferito fare in questo modo per evitare di dover creare due griglie separate. Lavorare su una sola 
griglia dinamica non è stato semplice, ma ha dato i suoi frutti.
